A one-line sick-day excuse for [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) on make.fun.

The excuse: stuck between floors in the building's lift, and the emergency
button just plays hold music — so today is off.

Run `main.ts` and it writes the single line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
